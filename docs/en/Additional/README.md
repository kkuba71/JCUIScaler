# Supplementary documents

The documents in this directory — **Static Analysis**, **Risk Analysis** and **RoadMap** — describe the development of JCUIScaler up to version 1.0: findings from code reviews, design decisions with their rationale, risks and the work plan.

They are not updated on an ongoing basis. They may be extended occasionally, but they do not reflect every change in the project.

**The current, maintained document is the Technical Specification** in the parent directory (`docs/en`). The rules for contributing changes are maintained in [`CONTRIBUTING.md`](../../../CONTRIBUTING.md), and further planning and new findings are tracked in the issues of the project repository.

Each document is available as PDF (readable in the browser) and DOCX.
