# Dokumenty uzupełniające

Dokumenty w tym katalogu — **Analiza Statyczna**, **Analiza Ryzyk** i **RoadMap** — opisują proces rozwoju JCUIScalera do wersji 1.0: ustalenia z przeglądów kodu, decyzje projektowe wraz z uzasadnieniem, ryzyka i plan prac.

Nie są na bieżąco aktualizowane. Mogą być uzupełniane okazjonalnie, ale nie odzwierciedlają każdej zmiany w projekcie.

**Aktualnym i aktualizowanym dokumentem jest Specyfikacja Techniczna** w katalogu nadrzędnym (`docs/pl`). Zasady wprowadzania zmian są utrzymywane w pliku [`CONTRIBUTING.pl.md`](../../../CONTRIBUTING.pl.md), a dalsze planowanie i nowe ustalenia — w zgłoszeniach w repozytorium projektu.

Każdy dokument jest dostępny w wersji PDF (do czytania w przeglądarce) i DOCX.
